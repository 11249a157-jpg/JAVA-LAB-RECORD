# Experiment 6(a): Arithmetic Operations in Java

## Aim
To write a Java program to perform arithmetic operations using a separate class and a demo class.

## Algorithm
1. Start the program.
2. Create an `Arithmetic` class with methods for addition, subtraction, multiplication, and division.
3. Create an `ArithmeticDemo` class containing the `main()` method.
4. Create an object of the `Arithmetic` class.
5. Read two numbers from the user.
6. Call the arithmetic methods using the object.
7. Display the results of all arithmetic operations.
8. Stop the program.

## Result
Thus, the Java program to perform arithmetic operations using separate classes was implemented successfully.
