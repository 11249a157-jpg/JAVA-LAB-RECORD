# Experiment 6(b): Area and Perimeter of Shapes

## Aim
To write a Java program using separate classes to calculate the area and perimeter of a circle, square, and triangle.

## Algorithm
1. Start the program.
2. Create a `Circle` class to calculate the area and circumference of a circle.
3. Create a `Square` class to calculate the area and perimeter of a square.
4. Create a `Triangle` class to calculate the area and perimeter of a triangle.
5. Create a `ShapesDemo` class containing the `main()` method.
6. Create objects of the three shape classes.
7. Call their methods and display the calculated areas and perimeters.
8. Stop the program.

## Result
Thus, the Java program to calculate the area and perimeter of a circle, square, and triangle using separate classes was implemented successfully.
